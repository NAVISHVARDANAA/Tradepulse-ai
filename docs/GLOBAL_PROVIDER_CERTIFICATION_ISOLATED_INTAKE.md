# Global provider certification and isolated intake readiness

Phase 8L defines the fail-closed certification and isolation controls required
before any provider-specific endpoint test or candidate observation intake.
No provider selection, endpoint test or isolated intake is implied by these
reference contracts.

## Unselected provider profiles

Eight provider-family profiles correspond to the disconnected source families
introduced in Phase 8K. Every profile begins with no selected provider, no
legal entity, no endpoint, no credentials and no certification. A missing
provider remains an explicit gap and cannot be replaced with a fixture,
assumption or synthetic approval.

## Ten certification gates

The reference gate set requires accountable legal ownership; contract and
access rights; display and retention rights; derivation and model-use rights;
privacy review; security and secret handling; endpoint and schema
certification; availability and rate-limit controls; revision and change
management; and accountable human activation. A later provider may advance
only through provider-specific evidence reviewed outside public views.

## Unprovisioned isolation profiles

Each provider family has an isolation profile with no provisioned environment,
network route, secret reference, retention approval or candidate payload. The
profiles define the required containment boundary without creating an ingress
path. Production tables and downstream intelligence views cannot receive data
from them.

## Evidence-required failure drills

Six templates cover credential rejection, schema drift, license or rights
withdrawal, stale or replayed observations, conflicting evidence and isolation
escape. All drills begin unobserved. Synthetic planning records are not
operational evidence and cannot satisfy an activation gate.

## Hard boundary

Provider selection, endpoint testing, credential storage, candidate intake,
production ingestion, automatic certification, observation release, model
training, autonomous publication and autonomous trade execution remain
database-constrained off. Reference records are append-only, public access is
limited to sanitized readiness views and production smoke verification is
query-only.

The future activation order remains provider-specific legal and rights review,
privacy and security approval, endpoint and schema certification, provisioned
isolated intake, bounded synthetic and failure testing, accountable human
activation, candidate quarantine and the independent Phase 8K release gates.
Phase 8L completes only the certification and isolation-readiness foundation.
