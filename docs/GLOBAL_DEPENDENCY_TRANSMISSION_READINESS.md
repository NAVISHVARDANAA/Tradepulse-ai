# Global dependency and transmission readiness

Phase 8J defines the evidence contract required to connect country intelligence
to causal market scenarios. It does not assert any live bilateral, commodity,
energy, logistics, currency, policy, corporate or climate relationship.

## Readiness fabric

The migration creates eight dependency domains for each of the 195 sovereign
references introduced in Phase 8I. All 1,560 country-domain cells begin as
`relationship_evidence_missing`, with zero verified upstream or downstream
links. No relationship is inferred from a country or domain alone.

| Domain | Evidence question |
| --- | --- |
| Bilateral trade | Which directed product or service flow, units, period and classification connect two economies? |
| Commodity supply | Which reserves, production, processing, consumption and substitution evidence supports the path? |
| Energy flows | Which origin, transit, storage, refining and destination evidence supports the dependency? |
| Logistics routes | Which corridor, capacity, delay and alternate-route evidence supports the path? |
| Currency and funding | Which invoicing, settlement, reserve, FX and funding evidence supports the exposure? |
| Monetary policy | Which rate, liquidity, inflation, funding and lag evidence supports transmission? |
| Corporate supply chain | Which filing, supplier, customer, product and concentration evidence supports the dependency? |
| Climate and regulatory | Which hazard, geography, legal scope and effective-date evidence supports the path? |

Each domain requires directed identity, magnitude evidence, a substitution
review, multiple independent sources and a bounded freshness window.

## Transmission templates

Six templates describe how verified evidence could later be assembled: supply
expansion, route disruption, currency repricing, rate change, climate shock and
regulatory change. They deliberately contain no probability, confidence or
effect estimate. A template cannot create a scenario or establish that a real
relationship exists.

## Human release gates

Source rights, directed identity, unit and scope, temporal alignment, exposure
magnitude, substitution path, uncertainty calibration and accountable human
release must all be reviewed before a dependency can support any scenario,
model or publication.

## Hard boundary

Live providers, relationship inference, generated gap filling, impact scoring,
scenario promotion, model training, autonomous publication and trade execution
are database-constrained off. Reference tables are append-only, public access is
limited to sanitized views and production smoke checks are query-only.

The future release order is evidence contract approval, source-specific
licensing and connection, observed relationship verification, independent
reconciliation, human release review, and only then a separately reviewed
scenario integration. Phase 8J completes only the first step.
