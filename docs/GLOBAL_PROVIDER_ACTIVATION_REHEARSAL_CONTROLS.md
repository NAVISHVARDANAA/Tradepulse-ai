# Global provider activation rehearsal and rollback verification

Phase 8T defines the isolation, synthetic-input, observability, abort,
restoration, reconciliation and closeout evidence that must exist before a
future provider-specific activation rehearsal could be authorized. It records
no real provider, runbook, environment, endpoint, credential, payload,
rehearsal window, drill or activation.

## Seven reference-only rehearsal states

The catalog covers `rehearsal_not_requested`, `runbook_required`,
`isolation_and_synthetic_inputs_required`, `pre_rehearsal_snapshot_required`,
`bounded_rehearsal_window_required`, `abort_restore_and_verify_required`, and
`closed_without_activation`. These are governance definitions, not a live
rehearsal workflow. Automatic transitions are disabled and no state grants
egress, credential, fixture, activation, write or production effects.

## Eight fail-closed rehearsal gates

Every source family must eventually prove current activation readiness,
non-production isolation, synthetic identities/secrets/payloads, pinned endpoint
contracts, observability and stop controls, rehearsed abort/restoration and
reconciliation, independent verification, and accountable closeout with expiry.
All gate templates are unmet and contain no evidence, reviewer or human
authorization.

## Sixty-four blocked rehearsal cells

The eight provider-neutral source families and eight rehearsal gates create 64
deterministic cells. Every cell is blocked and contains no runbook, activation
reference, environment, synthetic secret, snapshot, abort report, restoration
report, verification report, authorizer, rehearsal window or execution time.
Sanitized public views expose only these gaps.

## Hard boundary

Rehearsal-request recording, rehearsal scheduling, isolated egress tests,
synthetic secret binding, synthetic payload execution, abort/restoration drills,
reconciliation, provider selection, endpoint connectivity, credential storage,
payload intake, fixture execution, conformance approval, provider activation,
candidate writes, observation release, model training, publication and trading
remain database-constrained off. Reference records are append-only and
production smoke verification is query-only.

A future separately authorized rehearsal must establish an isolated expiring
environment, denied-by-default egress, synthetic-only inputs, ephemeral
non-production secrets, immutable audit, observable stop conditions,
deterministic restoration and reconciliation, independent post-rehearsal
verification, and accountable closeout. Phase 8T creates rehearsal-readiness
scaffolding only; it creates no provider testing or activation path.
