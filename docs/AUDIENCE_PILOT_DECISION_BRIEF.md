# Phase 9D audience pilot decision brief

Phase 9D converts one privacy-safe Phase 9C aggregate into a reviewable product
decision brief. It closes the gap between an audience research signal and an
accountable pilot discussion without pretending that software can authorize
outreach.

## Evidence contract

- Only a Phase 9C schema-version 1 aggregate export is accepted.
- The file is limited to 96 KB and exists only in the page's React memory.
- Identity/contact keys, email-like values, raw-text flags, retained-source flags
  and activation authority fail closed.
- Session counts, distributions, score ranges, gate count and the research
  decision must reconcile before a brief is produced.
- No source debrief, facilitator note, participant identity or contact detail is
  requested, persisted or included in the decision export.

## Decision output

The workspace preserves the Phase 9C decision state and produces:

- a plain-language collect, iterate, reframe or pilot-review recommendation;
- the strongest aggregate audience, usefulness, confusion and next-action
  signals;
- a prioritized experiment backlog tied to the unmet research thresholds;
- a fixed research-pilot envelope; and
- the external owner and evidence checks that remain incomplete.

The fixed envelope is a maximum of 30 participants for four weeks, free of
charge, using reference, delayed or clearly labelled curated demo data. Licensed
real-time data is not required for the research pilot.

## Authorization boundary

The copy and download actions create an unsigned local draft. They do not record
a decision, identify an owner, send an invitation, provision an account, enable
public signup, connect a data provider, display a licensed feed or trigger a
financial action.

Product, privacy, support, measurement, cost and rollback ownership still need
external evidence and an accountable human go or no-go decision. Phase 9D adds
no migration, server endpoint, analytics tracker or provider connection and
preserves migration 066 plus every Phase 8Z activation lock.

The web release confirmations are `BUILD_PHASE_9D`, `DEPLOY_PHASE_9D` and
`VERIFY_WEB_PHASE_9D`. Publishing the code does not run any of them.
